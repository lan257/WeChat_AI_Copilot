## 本次提交 `46a19c1` · 启动器支持本机代理配置，并恢复复制建议的兜底路径

改动 3 个文件，+37 / −2。

### 为什么要改

1. **AI 任务在这台机器上必然超时。** Codex 执行器固定带 `--ignore-user-config`（保证执行环境封闭），因此它不读 Windows 注册表里的系统代理，只认 `HTTP(S)_PROXY` 一类环境变量。这台电脑必须经本机代理才能访问模型服务，结果每条建议任务都跑满 180 秒硬时限并报 `RUNTIME_TIMEOUT`。
2. **复制建议失败时只剩一句报错。** 移植 V8 前端时按旧版实现只保留了剪贴板 API 一条路径，浏览器拒绝授权就直接失败；V8 原型本来有兜底。

### 改了什么

- `scripts/Start-FormalProject.ps1`：新增**可选**配置 `%LOCALAPPDATA%\WeChatAiCopilot\Formal\network.json`。
  - 文件存在且 `proxyUrl` 形如 `http(s)://host[:port]` 时，向 API 进程注入 `HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY`（`noProxy` 缺省时用 `127.0.0.1,localhost`），并提示“AI 连接将使用本机 network.json 指定的代理出口”。
  - 地址格式不合法时提示并按直连启动；文件不存在时**行为与改动前完全一致**。
  - 这四个变量加入原有的进程环境清理清单，不残留给其他子进程。
  - 只交给 API 进程使用；微信读取仍是本机只读，不产生对外连接。
- `docs/operations/Local_User_Guide.md`：在使用指南“生成回复建议和咨询”一节补上该配置写法，并说明任务长时间停在“正在执行模型”最终报 `RUNTIME_TIMEOUT` 通常就是这个出口没配。
- `src/WeChatAiCopilot.Api/wwwroot/v8/chat.js`：`copy()` 恢复三级兜底 —— 剪贴板 API → 隐藏只读文本域 + `execCommand('copy')` → 弹出可手动复制的文本框；三种结果给出不同提示，不再只报“复制失败”。

### 验证

- 重启正式项目后启动器输出代理提示，真实建议任务由超时变为 **Completed，26.7 秒，返回 3 条建议**。
- 复制兜底在受限浏览器中走到第三级（弹出可复制文本）；第二级 `execCommand` 的成功路径未能在该环境验证，需在真实浏览器点一次确认。
- PowerShell 脚本语法解析通过；前端模块按 ES 模块解析通过。

## 上次提交 `749b5bd` · 提出 V8.1 候选，为采集故障增加可见状态

新增 3 个文件（候选 Demo、校验和、状态说明），未改动任何正式代码。

### 为什么要提候选

真实数据验收时，被监听联系人的采集状态实际是 `Error`（读取器与本机目标集合冲突导致），但页面顶部仍显示“监听待就绪”，列表指示点也是普通灰色：使用者看到的是“正常等待”，实际已停止采集、新消息不会进入上下文。V8 原型只有“监听中 / 未监听”两态，没有给故障留位置，因此按审批门禁**先改 Demo**，批准后才动正式代码。

### 候选内容（`docs/product/candidates/V8.1/`）

以已登记的 V8 快照逐字节为起点，只加 5 处、净增 690 字符：

1. 顶部状态胶囊新增第三态“采集异常”（琥珀红 `#fdefec` / `#a4523c`），优先级高于“监听中 / 未监听”。
2. 会话头像右下小圆点新增 `.fault-mini`，与绿点（监听中）、灰点（未监听）并列。
3. 聊天区顶部新增 `#captureBanner` 横幅，仅故障时出现，说明“历史消息仍可阅读，新消息不会进入上下文”，并提供跳转「设置 → 应用与状态 → 运行状态」的恢复入口；形态沿用既有身份校准横幅。
4. 故障只改变显示，不改变“是否监听”的数据本身。
5. 演示数据给联系人「六月」标 `fault:true`，无需真实设备即可复核该状态。

三条建议位置、人设与分析深度共用规则、极简模式折叠范围、设置分组与子页返回、Skills 生命周期、历史补录统计、连接向导、配色与文案体系**全部保持 V8 原样**。

### 验证

在浏览器中打开候选 Demo：「六月」显示“采集异常”胶囊与故障点，横幅可见且带恢复入口；其余 3 个监听中联系人的绿点不受影响。截图见 `临时文件/inventory/v81-fault-demo.png`（工作区临时目录，未入库）。
