### 启动脚本故障修复

- 已复现 `py -3.11` 返回“未找到已安装的 Python”，同时常见的用户级 Python 3.11 可执行文件路径存在；启动器现会回退探测该路径及常见系统路径，并在初始化本机数据库前检查版本。
- 已定位本次报告的解析错误根因：脚本以无 BOM UTF-8 保存，Windows PowerShell 5.1 按系统代码页读取后产生连锁语法错误。脚本已保存为 UTF-8 BOM，并拆开服务筛选/正则中的引号；Windows PowerShell 5.1 与 PowerShell Core 均通过实际文件解析检查。
- 已增加首次会话配置：启动器提示输入联系人显示名，由 Reader 只在本机联系人表中做精确匹配；零匹配或多匹配均失败关闭，成功后在受限 LocalAppData 中保存范围和一次性确认指纹。匹配真实联系人和完整启动尚未实测。
- 修复 PostgreSQL 首次就绪探测：Windows PowerShell 5.1 可能把 `psql` 的暂时性 stderr（数据库启动中）提升为终止错误；探测现会捕获并在期限内继续重试。若 PostgreSQL 进程提前退出，仍会停止并报告未就绪。
- **2026-10-12 启动验收进展**：使用已授权的一个 Direct 会话完成首次范围确认；正式私有 PostgreSQL 与 API 就绪，Reader 历史导入回执为 93 条读取、93 条匹配、0 条新建/冲突/失败，Reader 心跳连续获 API 接受。报告和测试未包含聊天正文、账号 ID 或凭据。
- 启动器已打开 Web 地址并将 Web token 复制到本机剪贴板；内置浏览器安全策略不允许自动访问 localhost，因此页面授权后的聊天显示、建议生成和复制尚未由本轮代为验收。
