# 本机使用指南

本指南面向 Windows 普通使用者。正式项目固定连接一台电脑上的一个已授权微信一对一会话；微信读取保持只读，回复只能由使用者手动复制和发送。

## 启动

双击正式项目根目录中的 `启动正式项目.cmd`。第一次启动会准备本机正式数据库、补录所选会话最多 5,000 条文本消息，并打开 Web 工作区。启动脚本只把数据存放在当前 Windows 用户的 LocalAppData 和正式项目的忽略构建目录中。

启动器会先检查已准备的 Reader 运行组件和 Python 3.11，并自动查找常见的当前用户/系统安装路径；若缺少兼容运行时，会在创建本机数据库前停止并显示原因。

如果当前 Windows 用户尚未确认会话，启动窗口会要求输入微信联系人显示名。请先打开并登录微信，再输入要使用的一对一联系人的准确显示名。读取器只在本机联系人表中精确匹配这个名字；找不到或匹配到多个联系人时会停止，不会读取聊天正文或创建会话配置。确认成功后，范围配置保存在该 Windows 用户受限访问的 LocalAppData 中，后续启动不再询问。

如果微信客户端没有运行，脚本会打开已安装的微信客户端。请先在微信完成登录，再重新双击启动文件。历史补录超过 5,000 条或 Reader 无法读取时，启动会报告失败，不会使用示例消息冒充真实记录。

## 打开网页并连接

浏览器会打开电脑本机页面：`http://127.0.0.1:5080/`。启动窗口会把 Web 访问令牌复制到剪贴板；在网页令牌框粘贴后点“连接并读取”。令牌只需在本机使用，不要发给别人。

如果剪贴板内容被覆盖或网页刷新后需要重新输入，在正式项目目录双击 `Copy-WebToken.cmd`。它会从当前 Windows 用户受保护的本机凭据中重新复制同一个令牌，不会重启服务，也不会在窗口或日志中显示令牌。回到网页令牌框按 `Ctrl+V` 粘贴即可；不要在前面添加 `Bearer `。首次启动正式项目前还没有令牌，需先双击 `启动正式项目.cmd`。

目前服务器范围固定为启动时已授权的单个会话，网页不会列出或切换其他微信联系人。联系人显示名与历史记录导入后，工作区会显示该会话的最近 50 条消息；旧消息翻页尚未接入。

## 生成回复建议和咨询

在“聊天与 AI”页选择人设并点“生成建议”，系统通过本机 Codex CLI 为当前会话生成三条备选。点击任意备选旁的“复制”，再自行切换到微信手动粘贴和发送。系统不会自动发送微信消息。

AI 侧边栏可以针对当前会话提出问题并继续咨询。Codex CLI 可能需要等待一段时间；本机配置的单次硬时限为 180 秒。

## 极简模式

点页面顶部“极简模式”进入。页面提供三条备选、人设轮换、“换一批”和复制。复制后仍需由使用者回到微信手动发送。点展开按钮可返回工作区详情。

## 结束使用

在启动时打开的黑色 Reader 窗口按 `Ctrl+C`。Reader 会执行清理；启动脚本随后关闭 API 和本机专用数据库。不要直接在任务管理器结束 Reader 进程，以免中断清理。

## 手机与局域网

当前版本只绑定电脑本机地址。手机无法通过 `127.0.0.1` 访问这台电脑上的网页；手机地址也没有配置。项目尚未实现带可信 HTTPS 证书和局域网防火墙限制的手机访问，因此目前只能在运行项目的电脑上使用。不要把服务改成明文局域网监听。

## 当前使用限制

- 只支持一个微信账号和一个 Direct 一对一会话。
- 历史文本补录最多 5,000 条；非文本消息正文、附件和历史翻页当前未接入。
- 消息方向来自当前 Reader 的待确认映射。首次显示可能标注“默认方向 · 待确认”；使用者需要在“接入与会话”中核对本人/联系人的身份后再确认，才能把方向当作已验证结果。
- 启动脚本的 Web 令牌只对本机访问；每次启动都会复制到剪贴板。需要重新复制时可双击 `Copy-WebToken.cmd`，无需重启正在运行的服务。
- 手机局域网访问尚未实现。
