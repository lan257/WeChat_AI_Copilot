# 本机使用指南

面向 Windows 普通使用者。微信读取始终**只读**；软件不发送任何微信消息，回复只能由你复制后自己粘贴发送。消息与记忆保存在你这台电脑。你明确请求 AI 建议或咨询时，当前获准会话的必要上下文会交给你登录的 Codex CLI/OpenAI 服务处理。

## 第一次安装

收到发布包时，需要同一目录内的四个文件：zip、同名 .zip.sha256、Install-FromPackage.ps1、Agent_Install_Runbook.md。把四个文件交给能运行本机 PowerShell 的操作型 AI Agent，并让它按附件 Runbook 执行和验收。

如果由维护者在当前电脑直接准备源码目录，才运行 scripts/Setup-TrialMachine.ps1。普通接收者使用发布包，不克隆源码。

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Install-FromPackage.ps1 -PackageZip "./WeChatAiCopilot-<版本>-win-x64.zip" -RunSetup
~~~

发布包自带自包含应用和固定版 Reader 模块。Setup 会通过 winget 安装缺少的 PostgreSQL 18 与推荐版 Python 3.11；已安装的其他 64 位 Python 3.10+ 会先通过实际依赖导入检查，必要时尝试重新准备依赖。PostgreSQL 是机器范围安装，Windows 可能要求你本人批准 UAC；没有管理员权限或不批准时请联系维护者。接收机不需要 .NET SDK。哈希或清单核对失败时停止，不要跳过。

## 启动

双击正式项目根目录的 `启动正式项目.cmd`。它会自动完成：准备本机私有数据库 → 构建或复用预构建应用 → 启动网页服务 → 启动只读采集 → **打开浏览器并自动建立本机会话**（不需要复制任何令牌）。

首次启动默认把所选会话最多 5,000 条可读文本消息补录到本机私有数据库。如不希望导入，可由 Agent 使用启动参数跳过，Reader 仍会监听新消息。

首次运行会**列出本机可读取的一对一会话让你输入编号**（群聊与公众号不会出现在列表里）。这个选择只是起点，之后可以随时增减。列表来自本机微信，找不到或输入无效时不会写入任何配置。

微信没在运行时会先帮你打开微信；请在微信里完成登录，再重新双击启动。

## 结束使用

双击 `关闭正式项目.cmd`。启动时那个窗口显示「本窗口可以关闭」后可以放心关掉，它不是服务本体，也不需要在里面按 `Ctrl+C`。

## 添加或减少联系人

「设置 → 联系人与会话 → 后台监听」里逐个开关，最多同时监听 **20 个**一对一会话。

- 打开开关后，只会收到**从此刻起的新消息**；
- 这个人的**历史消息不会自动进来**，需要在「设置 → 联系人与会话 → 历史补录」里点一次「同步历史消息」。

## 阅读消息与翻页

工作区中间是聊天窗口，默认加载最近 50 条，点顶部的「↑ 加载更早消息」可以继续往前翻，直到本次可读记录的起点。

## 产品内置 AI Agent

正式启动器会设置产品 Agent 使用本机 Codex CLI。没有 CLI 或没有登录时，工作区与 Reader 仍可运行，但 AI 建议和咨询不可用。

需要 AI 功能时，按[OpenAI 官方 Codex CLI Windows 安装说明](https://github.com/openai/codex#quickstart)安装，并由你本人完成 codex login。程序不要求固定 Codex CLI 版本；安装后在新的 PowerShell 查看 codex --version 和 codex login status，再通过一次实际请求确认兼容。不要把认证文件、API key 或 token 发给别人。

产品用户明确请求建议或咨询后，当前获准会话的必要上下文会交给你登录的 Codex CLI/OpenAI 服务处理。部署助手不得在未获你明确同意时用真实会话做 AI 冒烟。程序不会代替你向微信发送消息。

## 生成回复建议与咨询

右侧 AI 面板底部有**人设**和**分析深度**两个下拉，同一会话的建议、咨询和极简模式共用这一套设置。

- 点第三个快捷按钮「生成三条回复最新消息的参考」，本机实测快速档约 20 秒，其余深度约 30–60 秒；
- 点任意一条即复制到剪贴板，然后你自己切到微信粘贴发送；
- 在下方输入框提问，可以就这段聊天继续咨询，回答会标注参考了几条当前会话证据。

分析深度分快速 / 平衡 / 深度 / Max，对应读取的近期消息条数与是否复核。**快速档一定只有一次模型调用**，即使启用了复核类 Skill 也不会追加复核；平衡和深度在启用复核类 Skill 时多一次复核，Max 始终独立复核。运行状态里能看到最近一次建议的分段耗时。

需要走本机代理时，在 `%LOCALAPPDATA%\WeChatAiCopilot\Formal\network.json` 写入
`{"proxyUrl":"http://127.0.0.1:端口","noProxy":"127.0.0.1,localhost"}` 后重启；没有这个文件时按直连启动。
代理只给 AI 连接使用，微信读取仍然只在这台电脑上进行。

**出口不通时会直接说清楚**：启动器在配置代理后会立刻探测那个端口连不连得上，连不上就在启动窗口写一行警告；
之后 AI 任务失败会显示“AI 连不上模型服务：本机代理或网络出口没有就绪”（错误码 `CODEX_CLI_NETWORK_FAILED`）。
任务长时间停在「正在执行模型」最终报 `RUNTIME_TIMEOUT` 也通常是同一个原因。把界面上的英文错误码原样发回来即可，不用截图聊天内容。

## 极简模式

点顶部「极简模式」。三条建议与「换一批」始终可见；右上角的展开/折叠**只控制人设、分析深度和“打开工作台”按钮**的显示，不影响建议。

## 自动识别消息发送者

读取器会从所选微信账号目录取得本账号 wxid，并按每条消息所在的 `message_N.db` 分片解析发送者 wxid。本人和联系人由这两个稳定 wxid 比较得出，不需要逐个会话确认或互换方向。若源数据中没有可信发送者 wxid，消息会标为「发送者未知」，不会被当作本人发言或用来生成长期记忆。切换微信账号时，账号目录与 wxid 绑定会分别保存。

## 历史补录的当前边界

补录有两种：**最近 90 天**（最多 5,000 条）和**本机全部历史**（不限时间窗口，单次最多 200,000 条）。两者都按 keyset 分页流式导入，超过一页不会整体失败。

全量导入**可以续扫**：进度按“已经写进本机数据库的位置”记录，所以中途关机、读取器退出或任务超时后，再点一次「导入本机全部历史」会从上次的下一条继续，不会重复导入。补录页会显示已扫描 / 已匹配 / 新补录 / 已忽略非文本；若本次是续扫，还会提示“本机该范围累计已扫描 N 条，含此前中断的扫描”。

单次补录有执行硬时限：有界窗口 60 分钟，全量导入 8 小时。超时任务分别标记为 `READER_JOB_DEADLINE_EXCEEDED` 并释放队列，重新点一次即可从游标继续。

## 手机与局域网

代码里已有设备配对与 HTTPS 开关（`scripts\Enable-LanHttps.ps1`），但**尚未在真机上完成验收**。在此之前请把本程序当作只在这台电脑上使用，不要把它暴露到明文局域网。

## 已知限制

- 只支持 Windows 上已登录的微信桌面版本机数据；不读取云端或其他设备的历史。
- 非文本消息（图片、语音、视频、文件）只记录类型，不导入正文与附件。
- 群聊与公众号不支持。
- 数据库结构升级前，启动器会自动完整备份并做一次恢复演练，演练不通过就不会开始升级；备份保留最近 10 份在 `%LOCALAPPDATA%\WeChatAiCopilot\Formal\backups`。仍没有定期备份和异地副本，长期不启动的电脑请自行另存一份。
- 采集出现故障时，界面目前仍可能显示「监听待就绪」而不是明确的故障提示（该状态已作为 V8.1 候选提交，待批准后实现）。
