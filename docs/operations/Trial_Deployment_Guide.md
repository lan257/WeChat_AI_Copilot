# 给朋友装「知间」· 极简版

这份只有两种做法，选一种即可。全程不需要朋友读技术文档。

> 交给朋友的东西：`artifacts\release\` 里的**三样**——安装包 `WeChatAiCopilot-<版本>-win-x64.zip`、它的
> `.sha256`、以及 `Install-FromPackage.ps1`（都在包外，见 `docs\operations\Release_and_Upgrade.md`）。
> 包里的应用是自包含的，朋友**不需要装 .NET SDK**，也不需要任何编译；不要再整个拷贝 `product` 文件夹
> （那会带上源码、构建中间产物和 `.git`，体积大且没有额外信息）。
> 如果朋友电脑上已经有整个项目目录（例如开发者本人），直接跑 `scripts\Setup-TrialMachine.ps1` 也可以。

## 做法一（推荐）：让朋友把一句话贴给自己的 AI 助手

朋友电脑上如果装了 Qoder / Codex / Claude 之类的 Agent，直接把下面这句发给它：

> 请按 `<项目路径>\product\docs\operations\Agent_Install_Runbook.md` 在这台电脑上安装并自检「知间」，遇到需要我本人决定的地方问我。

Agent 会自己完成：检查环境 → 跑安装脚本 → 启动 → 自检 → 汇总反馈。
手册里已经写死了红线：只读、只授权一个联系人、不得把聊天内容写进日志、不得代做选择。

## 做法二：朋友自己动手，四步

1. **装两个东西**（如果没装过）：微信桌面版（登录并停在聊天窗口）、以及下面脚本会自动安装的 PostgreSQL 18 与 Python 3.11。
2. **双击一次安装脚本**：把三样文件放进同一个文件夹，在该文件夹地址栏输入 `powershell` 回车，执行
   `powershell -NoProfile -ExecutionPolicy Bypass -File Install-FromPackage.ps1 -PackageZip "WeChatAiCopilot-<版本>-win-x64.zip" -RunSetup`
   它会核对安装包哈希、逐文件校验清单、装到 `%LOCALAPPDATA%\Programs\WeChatAiCopilot`，然后接着准备组件。
3. **看到每一行 `[OK]` 和最后的 `准备完成。`** 即成功；桌面会有两个快捷方式。
4. **以后每天只用两个快捷方式**：双击「知间 启动」→ 浏览器自动打开工作区；用完双击「知间 停止」。
   首次启动会**列出本机联系人让朋友输入编号**，选一个当起点即可（群聊和公众号选不到）。
   想让别人也进来：「设置 → 联系人与会话 → 后台监听」里打开开关就行，最多 20 个一对一会话，
   不用重装也不用改任何配置。

## 朋友需要知道的三件事

- 首次启动会在后台导入本机已有的历史文本消息，**不限最近 90 天**；导入没完成或失败时，
  「设置 → 应用与状态 → 运行状态」里的「本机历史导入」会写明原因。想要某个联系人的全部本机记录，
  在「设置 → 联系人与会话 → 历史补录」点「导入本机全部历史」，中断过也会从上次位置继续。
- 生成三条建议：快速档实测约 20 秒，更深档位或启用复核 Skill 约 30–60 秒。
  如果一直转圈最后报 `RUNTIME_TIMEOUT`，是访问模型的网络出口问题，把情况反馈回来即可。
- 所有聊天内容只存在朋友自己电脑上，程序不会发送任何微信消息，也没有自动发送功能。

## 反馈怎么收

让朋友按 `docs/operations/Agent_Install_Runbook.md` 第 6 节的 7 条回答，**不要截图聊天记录**。

## 发给朋友的话（可直接复制）

> 你手上应该有三个文件：安装包（.zip）、它的 .sha256、还有 Install-FromPackage.ps1。把它们放在同一个文件夹里，
> 先登录微信并停在聊天窗口。在那个文件夹地址栏输入 `powershell` 回车，粘贴执行：
> `powershell -NoProfile -ExecutionPolicy Bypass -File Install-FromPackage.ps1 -PackageZip "安装包文件名.zip" -RunSetup`
> 一路等它显示「准备完成」。之后双击桌面的「知间 启动」，它会让你输入一个编号选择要授权的联系人，
> 选完浏览器会自动打开。用完双击「知间 停止」。
> 如果弹出一个蓝色「已保护你的电脑」窗口，那是因为这个包还没做代码签名：点「更多信息」→「仍要运行」即可，
> 不要关闭电脑的安全功能。安装包哈希我会单独发给你核对。
> 如果你电脑上装了 AI 助手，直接把 `docs\operations\Agent_Install_Runbook.md` 这个文件（解压后在里面）发给它，
> 说“按这个文档帮我装好并自检”，它会替你做全部步骤，只在需要你决定的地方问你。
> 遇到任何报错，把屏幕上的英文错误码原样发给我就行，不用截图聊天内容。
> 补充：首次只让你选一个联系人当起点，之后想让别人也进来，在「设置 → 联系人与会话 → 后台监听」
> 里打开开关就行，最多可以同时监听 20 个人，不用重装。

## 什么情况下这套东西装不上

| 情况 | 结论 |
| --- | --- |
| 32 位 Windows | 不支持 |
| 微信未登录或停在登录界面 | 取不到本地库密钥，报 `WECHAT_DATABASE_UNAVAILABLE`；登录后重跑即可 |
| 公司电脑有管控/杀软 | 读微信进程内存可能被拦；需朋友自行决定是否加排除项，或换台电脑 |
| 微信以管理员运行 | 普通权限取不到密钥，需同等权限运行 |
| 拿不到 `artifacts\app\win-x64` 且没装 .NET SDK | 应用本体缺失，需要开发机重新生成后一起复制 |
